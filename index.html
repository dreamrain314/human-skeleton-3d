请用本地服务器打开

浏览器不允许 file:// 页面加载 ES module 和 .glb 模型文件， 所以直接双击 index.html 只会停在这一页。

  1. 回到本文件夹，双击 start.bat（Windows）
  2. macOS / Linux 双击 start.command
  3. 或在本文件夹里执行 python -m http.server 8765，再访问 http://localhost:8765
